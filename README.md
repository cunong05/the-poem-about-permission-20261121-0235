A short poem about agency — the power to ask and to be given. Two words open the only door that opens from the other side: "May I?"

## Run it

```sh
node main.ts
```

The program writes the poem to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to change the destination). It checks the poem first — UTF-8 text of 1 to 280 characters — and writes the same bytes on every run, so repeated runs always produce the same file.
